# Формализация расчёта КНС (Lean 4 + Mathlib)

Инструмент проверки, не реализация: JS (`static/js/hydro.js`) остаётся
исполняемой версией, Lean — офлайн-сертификат её соответствия методичке
(НИИ ВОДГЕО, пример п. 5.1). Никаких доказательств над float.

## Что доказано

`Formal/Certificate.lean` (автоген, 182 теоремы; для каждой из шести
напечатанных строк Q_нс = 100…200 л/с при Qr = 342,3, t_r = 10, n = 0,71):

* `W_bounds` — W формулы (1) при **точном** T_н формулы (2) и табличном T_к
  сжат рамкой ~2·10⁻⁴ (точное значение тоже известно: генератор, строка 1 —
  113,7880);
* `W_printed` — |W − печать| ≤ 0,05, т.е. печать таблицы — округление точного
  W (худшая строка 150: точное 74,6528… против 74,7);
* `Tn_bounds` — точный T_н формулы (2) в рамке 10⁻⁶ (при Q_нс = 100 точное
  0,143621, в тексте методички 0,14);
* `root_exists` + `g_lo`/`g_hi` — смена знака g − Q_нс на
  [T_к−0,005; T_к+0,005] и IVT: корень формулы (3) лежит там, т.е. печатный
  T_к верен с шагом 0,01.

`Formal/Graph.lean` (голый `Init`, без Mathlib): модель графа каскада из
`static/js/cascade.js`; «пригодный порядок ⇒ ацикличен» и контрпример
`cascadeCycle_not_topo` — формализация дыры, когда `topoOrder` молча
дописывает потерянные узлы вместо отказа.

## Как устроен сертификат

Тактики `interval` в Mathlib4 нет. Граница иррационального атома X^(p/q) —
это пара целочисленных сравнений в ℚ (L^q ≤ X^p < U^q), которые проверяет
`native_decide`; перевод в ℝ делают рукописные мосты `rpowRat_le_iff` /
`rpowRat_lt_iff` (только propext/choice/Quot.sound). Python
(`tools/gen_bounds.py`) — калькулятор границ: бисекция по целочисленной
решётке на точных дробях; float определяет только догадку кандидата T_к,
а её Lean перепроверяет знаком g на концах. Сфабрикованная граница роняет
сборку; `sorry` в проекте нет. Аксиомы `native_decide` перечисляются в
журнале сборки (`#print axioms` вшиты в конец `Certificate.lean`).

## Запуск

```bash
# toolchain leanprover/lean4:v4.33.1 + Mathlib v4.33.1 (кэш lake, ~7,5 ГБ .lake)
cd formal
lake update            # один раз; исходники Mathlib не компилируются
python3 tools/gen_bounds.py   # перегенерировать Certificate.lean (детерминированно)
lake build                    # ~12 с, «Build completed successfully (3010 jobs)»
```

## Изменение данных

Правки в `ROWS` генератора (Q_нс / печать T_к / печать W) — перегенерировать
и пересобрать. Расхождение печати с формулой больше 0,05 — сборка падает на
assert'е генератора ещё до Lean.

## Что сознательно НЕ доказано

* Единственность корня T_к (монотонность g требует лемму субаддитивности
  (p+q)^a ≤ p^a + q^a, в Mathlib её нет) — существует и локализован с
  шагом 0,01, чего для таблицы достаточно.
* Совпадение `calc()` из `hydro.js` с формулой (1) как синтаксический тождество
  кода: JS-тесты (`node --test tests/*.test.js`) сравнивают числа, Lean —
  математику.
